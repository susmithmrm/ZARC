# Interactive modern sedan

The public architecture page includes an original procedural four-door sedan, rendered in WebGL with locally bundled Three.js r180 (MIT). The vector projection is a fallback. Forty-four selectable reference components cover ZARC companion, zones, integrated island, smart edge, central compute and independent vehicle ECUs; safety-related domains remain independently allocated. Network lines are illustrative semantic/physical connection categories, not a wiring or harness design. Controls include orbit, zoom, top/side/cabin views, cutaway, transparency, exploded electronics, ZARC focus and per-network filtering. No OEM CAD asset, vendor endorsement, hardware qualification or real vehicle telemetry is implied.

The publication verification plan checks JavaScript syntax and vector renderer controls. Visual quality and GPU/browser performance require browser testing.
