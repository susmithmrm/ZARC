# Local authority and bounded work

The controller now admits a trusted local policy request without a connected host or request ledger. Shared endpoints serialize local and remote work; pending work is not implicitly preempted. The benign reference uses first-admitted precedence and BUSY for conflicts. No vehicle-specific priority or arbitration approval is implied. A local request needs an externally approved policy decision and a reserved effect slot.

Remote cancellation distinguishes denied, unknown, already terminal, in-flight and removed-before-execution. Removal is accepted only after the sole adapter owner proves synchronized removal before physical execution. It does not fabricate a reversed observation; the ledger retains UNKNOWN_OUTCOME as the conservative existing wire result. In-flight cancellation is refused, not presented as undo. An OEM cancellation protocol and terminal wire result are still required if selected.

The portable schedule helper tracks absolute release phase, skipped cycles and deadline misses without unbounded catch-up. The C3 traffic queue has separate core and bulk capacities, explicit overflow metrics and core-first retrieval. It is a single-owner data structure, not a replacement for Zephyr kernel queues; an actual selected broker/provider must use it and analyze bulk starvation. Tests cover disconnected local behavior, conflicting admission, cancellation preconditions, timing drift and bulk saturation. Trace candidates: SYS-001/003/008, RT-008/013/014, SVC-012. Product authority, actual scheduling, queue measurement and HIL remain open.
