# Portable connect contract increment

Candidate lab envelope: 32-byte header with magic ZR, exact major/minor 1/0, operation byte, zero reserved byte, little-endian 16-bit payload length (maximum 256), 64-bit boot/session/request identifiers, then payload. This is a private lab framing candidate, not SOME/IP or an authenticated wire protocol. Malformed streams fail closed, requiring transport reset. No checksum or cryptography is provided by this framing layer.

The single-owner link object accepts only externally verified principal and policy inputs. It does not authenticate a peer, check a product-specific domain enum, establish clock trust or dispatch hardware. Transit age must be established externally; unknown age refuses fresh admission. Result capacity is reserved before admission; the caller must coordinate reservation with domain-effect capacity. Results are retained through the session; a new session is refused while accepted work remains pending, and old-session records are discarded only when a new session opens. Completion comes from independent feedback or explicitly unknown outcome. Disconnect does not cancel accepted work. Boot identity is external and must be unique. Snapshot cache detects event sequence gaps and epoch mismatch; caller owns authorization, expected current session, stale-age policy and snapshot subscription barrier.

Trace candidates: CON-002 through CON-009, CON-014 through CON-016, and SVC-007. Tests cover independent link instances, conflicting retries, expiry, saturation, disconnect, frame boundaries and snapshot gaps. This does not close the corresponding requirements. Broker integration, typed payload schemas, actual peer authentication, replay protection across resets, provider conformance, snapshot race reconciliation and physical transport evidence remain open.
