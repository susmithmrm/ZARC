# ZARC verification record template

Informative template for Z12; repeat for each applicable requirement/configuration/test instance.

| Field | Record |
|---|---|
| Requirement ID, verification ID, design reference, method and planned gate | TBD |
| Configuration identity, source and dependency versions, toolchain, binary and manifest hashes | TBD |
| Profile, board/stepping, physical or simulator identity, fixture version and calibration | TBD |
| Applicability: applicable, not applicable with reviewed rationale, or unresolved with owner | TBD |
| Scope: configuration, release, program or portfolio | TBD |
| Procedure, allocated workload, conditions, timing source and measurement uncertainty | TBD |
| Expected acceptance and test category (positive/negative/boundary/integration or approved exclusion) | TBD |
| Actual result, raw evidence path/hash, model limitations and physical correlation | TBD |
| Verdict (NOT RUN / PASS / FAIL / BLOCKED), deviations and open dependencies | NOT RUN |
| Accountable reviewer, independence, approval identity and date | TBD |

Evidence must correspond to the actual configuration and acceptance criterion. Do not substitute simulated evidence for a physical requirement, an observed maximum for WCET, or a structural check for an accepted engineering verdict. Confidential evidence is handled under allocated access policy. Refer to VER-001/004/006/009/011/022/023.
