# ZARC — Global partner adoption guide

> **ZARC 2035 | Architecture specification | Design phase.** The single requirements register is [Z12](12-Requirements-Verification.csv) (267 requirements). Implementation and verification are planned for the next phase.

## Integration sequence
Choose intended function, deployment profile, physical target and stakeholder role. Obtain pinned SDK and exact supported configuration; allocate customer requirements, quality, ownership and timing. Integrate with native Zephyr and selected standards. Demonstrate observability, replaceability, supported upgrade and recovery, independent conformance and physical tests. Compare cost with equivalent baseline. Protect customer IP and avoid mandatory core forks.
| Partner | Entry deliverable |
|---|---|
| OEM | Current/future topology and migration package |
| Tier 1 | Multi-customer integration and evidence |
| Tier 2 | Small module with independent conformance |
| Silicon | Native target port, driver and errata evidence |
| AI/tools | Optional bounded provider and versioned exchange |
No hardware support or commercial relationship inferred from an architecture candidate.
