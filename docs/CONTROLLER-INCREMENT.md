# Integrated controller increment

The single-owner controller composes the existing indicator domain and connect ledger for up to four independently configured benign endpoints. A request stages both ledger and domain before accepting, requires explicit reserved effect capacity, and returns a typed effect without claiming physical completion. Independent observations carry boot identity, sequence and source tick. Pre-admission samples cannot confirm a new command, and exact deadline is exclusive. A disconnected link does not stop local observation. The caller owns the actual queue reservation, readiness checks, authority, source clock trust and boot identity.

Trace candidates: CON-005/006/007/008/009/012/014/016 and SVC-007. Contract fixtures cover reservation failure, duplicate, concurrent independent endpoints, disconnected completion, reconnect, old epoch, stale feedback and exact timeout. Quality is derived at snapshot time; generation currently counts observed value transitions, not all quality transitions. No target timing, authorization or safety claim. The reference domain is still benign and intentionally not a generic actuator API. The broker, native execution adapter and independent device/provider are separate work.
